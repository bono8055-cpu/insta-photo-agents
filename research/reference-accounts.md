# 감성 사진 레퍼런스 계정 조사

- 조사일: 2026-09-27
- 범위: 한국 개인 계정 13개 + 해외 개인 계정 5개 (총 18개)
- 확인 방법
  - 팔로워 수·바이오: 각 인스타그램 프로필 페이지의 공개 메타데이터(og:description)를 조사일에 직접 조회했다.
  - 캡션 길이·게시 형식·게시일: 계정별 최근(또는 검색 노출) 공개 게시물 3~6개의 메타데이터를 조회했다.
  - 사진 톤: 같은 게시물들의 썸네일을 직접 보고 서술했고, 참고용으로 썸네일 평균 밝기(L, 0~255)와 평균 채도(S, 0~100)를 측정했다. 표본이 적어 경향 참고용이다.
  - "2차 출처"로 표시한 항목은 게시물을 직접 열지 못해 기사·큐레이션 글에 의존한 부분이다.
- 사진·캡션 원문은 옮기지 않고 특징만 요약했다.
