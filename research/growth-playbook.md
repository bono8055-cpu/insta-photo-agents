# 감성 사진 계정 성장 플레이북 (조사일 2026-09-27)

대상: 개인 감성 사진 계정(사진 + 짧은 글), 한국어 사용자 중심.
표기 규칙: 각 항목은 [내용 / 근거 / 출처 URL(게시·갱신 시점) / 우선순위 상·중·하]로 정리했다. 1차 출처(Instagram·Meta·Mosseri)를 우선했고, 1차 원문을 직접 열람하지 못해 2차 보도로 확인한 경우 "(2차 보도)"로 표시했다. 출처가 없는 업계 통념은 "통념(미검증)"으로 표시했다.

## 1. 추천 알고리즘 신호 (2025~2026)

### 1-1. 핵심 3대 신호: 시청시간·좋아요/도달·공유(보내기)/도달
- 내용: Mosseri가 "랭킹에 가장 중요한 세 신호는 시청시간, 좋아요, 보내기(sends)"라고 밝혔고, 인사이트에서 평균 시청시간·도달 대비 좋아요·도달 대비 보내기를 보라고 했다. 좋아요는 팔로워(연결된 콘텐츠)에, 보내기는 비팔로워(비연결 콘텐츠) 도달에 조금 더 중요하다고 했다.
- 근거: Mosseri 영상 발언을 인용한 보도(2차 보도). 영상 원문은 텍스트로 검증 불가. RecurPost 조사는 "보내기가 단일 최중요 신호"라는 주장은 Instagram/Meta 문서에서 찾지 못했다고 지적한다 — 3대 신호 중 하나로 보는 것이 정확하다.
- 출처: https://www.socialmediatoday.com/news/instagram-shares-algorithm-insights-2025/738034/ (2025-01-22) / https://blog.recurpost.com/instagram-ranking-signals-published-vs-invented/ (2026-08 작성, 출처 열람일 2026-08-24)
- 우선순위: 상 — 비팔로워 도달을 원하면 "DM으로 보내고 싶은 사진·문장"이 1순위 설계 기준.

### 1-2. Meta 투명성 센터 시스템 카드: DM 공유 예측, 캐러셀 스와이프 예측이 공식 입력값
- 내용: Instagram Feed 카드는 "게시물을 DM으로 공유할 가능성", 캐러셀 스와이프 가능성, 건너뛸 가능성 등 10개 주요 예측을 나열한다. DM 공유 예측의 입력 신호로 "게시 90일 이내 여부"가 들어간다. Feed(팔로우 콘텐츠)와 Feed Recommendations(추천 콘텐츠)는 별도 카드·별도 시스템이다. Explore는 후보 검색(retrieval) → 초기 랭킹 → 후기 랭킹의 다단계 구조다. 릴스 체이닝 카드에는 "릴스를 3초 미만 볼 가능성"이 예측 항목으로 있다.
- 근거: Meta 공식 시스템 카드. 카드 페이지는 JS 렌더링이라 본문을 직접 파싱하지 못했고, 카드 내용은 RecurPost의 인용(카드 갱신일 명시)으로 확인했다.
- 출처: https://transparency.meta.com/features/explaining-ranking/ig-feed/ (갱신 2026-06-29) / https://transparency.meta.com/features/explaining-ranking/ig-feed-recommendations/ (갱신 2026-06-29) / https://transparency.meta.com/features/explaining-ranking/ig-explore/ / https://transparency.meta.com/features/explaining-ranking/ig-reels-chaining/ (갱신 2025-11-11) / 인용: https://blog.recurpost.com/instagram-ranking-signals-published-vs-invented/
- 우선순위: 상 — 캐러셀 스와이프율과 DM 공유가 공식 예측 항목이라는 점이 사진 계정의 캐러셀 전략 근거.

### 1-3. 추천 신호: 좋아요·댓글·공유·저장의 양과 속도
- 내용: Instagram은 추천 개인화에 "얼마나 많은 사람이, 얼마나 빠르게 좋아요·댓글·공유·저장을 하는지", 작성자와의 상호작용 이력 등을 본다고 밝혔다. Explore는 대부분 비팔로워 계정의 추천으로 채워진다.
- 근거: Instagram for Creators 공식 블로그.
- 출처: https://creators.instagram.com/blog/tips-for-improving-your-reach (2023-05-31) / https://creators.instagram.com/blog/instagram-recommendations-eligibility-tips-creators (2022-08-30, 2023-04-25 갱신)
- 우선순위: 중 — 저장은 공식 문서에 "신호의 하나"로만 언급되며, 저장의 상대적 가중치를 밝힌 1차 자료는 찾지 못함.

### 1-4. 원본성(Originality): 사진·캐러셀까지 확대 (2026-04-30)
- 내용: 남의 콘텐츠를 주로 재업로드하는 계정은 사진·캐러셀·릴스 모두 추천 대상에서 제외된다. 최근 30일(롤링) 동안 게시물 대부분이 원본이면 다시 추천 대상이 된다. 미국 추천의 75%가 원본 게시물에서 나온다고 밝혔다. 팔로워에게 보이는 방식에는 영향 없음.
- 근거: Instagram for Creators 공식 발표.
- 출처: https://creators.instagram.com/blog/rewarding-original-creators-on-instagram (2026-04-30)
- 우선순위: 상 — 이 계정은 직접 찍은 사진만 올려야 한다. 타인 사진 리그램·큐레이션 게시는 비중이 커지면 추천 자격을 잃는다.

### 1-5. 워터마크·테두리·저해상도는 덜 노출
- 내용: 워터마크가 있거나 저해상도, 테두리가 있는 릴스, 대부분 텍스트인 릴스는 덜 보이게 한다고 밝혔다. 다른 앱 워터마크가 있는 콘텐츠·재게시는 추천 가능성이 낮다.
- 근거: Mosseri의 랭킹 설명 글과 Creators 블로그.
- 출처: https://about.instagram.com/blog/announcements/instagram-ranking-explained (2023-05-31, 작성 시점 기준 진술) / https://creators.instagram.com/blog/tips-for-improving-your-reach (2023-05-31)
- 우선순위: 중 — 사진에 서명 워터마크·흰 테두리 프레임을 넣지 않는다.

### 1-6. 2026 방향: "다듬어진 미학"보다 진정성·출처 신호
- 내용: Mosseri는 2025년 마지막 날 게시한 연말 메모에서, AI 콘텐츠가 넘치며 크리에이터들이 덜 다듬어진 콘텐츠("rawness as proof")로 가고 있고, 신뢰는 "무엇이 보이느냐"보다 "누가 공유하느냐"에 달리게 될 것이라고 했다. 사람들이 개인적 콘텐츠를 피드 대신 DM으로 공유한다고도 언급했다.
- 근거: Mosseri 게시물(20장 캐러셀)을 요약한 보도(2차 보도). "알고리즘이 raw 콘텐츠를 가중한다"는 구체적 랭킹 변경은 1차 문서에서 확인하지 못함.
- 출처: https://www.socialmediatoday.com/news/instagram-chief-outlines-the-challenges-of-ai-content/808674/ (2026-01-01) / https://om.co/2026/01/01/what-is-instagrams-adam-mosseri-really-saying-in-his-year-end-memo/ (2026-01-01)
- 우선순위: 중 — 감성 사진 계정에 유리. 과도한 AI 보정·생성 이미지를 피하고 "사람이 찍고 쓴 흔적"(촬영 맥락, 개인적 문장)을 남긴다.

### 1-7. 추천 자격 확인: 계정 상태(Account Status)
- 내용: 계정 상태 메뉴에서 콘텐츠·계정이 비팔로워 추천 대상인지 확인할 수 있고, 추천 가이드라인 위반 콘텐츠는 팔로워에게는 보여도 Explore·검색·릴스에서는 추천되지 않는다.
- 근거: Instagram for Creators 공식 블로그.
- 출처: https://creators.instagram.com/blog/tips-for-improving-your-reach (2023-05-31) / https://creators.instagram.com/blog/instagram-recommendations-eligibility-tips-creators (2023-04-25 갱신)
- 우선순위: 상 — 월 1회 계정 상태 점검.

### 1-8. 흔한 통념 중 1차 근거 없는 것
- 내용: "첫 1시간 반응이 전체 도달을 결정", "게시 후 캡션 수정 시 도달 감소", "고정 게시 빈도 필수", "비즈니스/크리에이터 전환 시 도달 감소", "캡션 링크가 도달 억제", "해시태그 개수가 도달을 바꾼다" — 모두 Instagram/Meta 1차 문서에서 근거를 찾지 못했다고 RecurPost가 정리. 이 항목들은 통념(미검증).
- 출처: https://blog.recurpost.com/instagram-ranking-signals-published-vs-invented/ (출처 열람일 2026-08-24)
- 우선순위: 하 — 에이전트가 이런 규칙을 만들어 따르지 않도록 참고.

## 2. 형식 전략 (단일 / 캐러셀 / 릴스, 비율)

### 2-1. 캐러셀이 단일 사진보다 도달이 높은 이유 (Mosseri)
- 내용: Mosseri는 캐러셀이 단일 사진보다 도달이 높은 이유로 (1) 여러 장이라 상호작용이 늘고, (2) 첫 장에서 스와이프하지 않은 사람에게 두 번째 장을 자동으로 다시 보여주는 "두 번째 기회"를 준다는 점을 들었다. 캐러셀은 최대 20장, 음악 추가 가능.
- 근거: Mosseri 게시물 인용 보도(2차 보도).
- 출처: https://www.socialmediatoday.com/news/ig-chief-recommends-posting-carousels-improve-reach/730232/ (2024-10-17)
- 우선순위: 상 — 기본 형식을 캐러셀로. 1장·2장 모두 "첫 장 역할"을 할 수 있게 강한 컷을 둔다.

### 2-2. 음악을 넣은 사진·캐러셀은 릴스 탭 노출 대상
- 내용: 음악이 들어간 단일 사진과 캐러셀은 릴스 탭에 노출될 수 있다(비팔로워 도달 경로). 2024년 10월 발표, 2025년 여름 @creators가 재공지.
- 근거: @creators 스레드 게시물(1차), 발표 당시 보도.
- 출처: https://www.threads.com/@creators/post/DLIOdJLKiXw/ (2025년 여름 추정 — 게시물 날짜 표시는 직접 확인 못 함) / https://www.lindseygamble.com/blog/instagram-expands-the-reach-of-carousels-and-photos-by-featuring-them-in-the-reels-tab-heres-why-it-matters (2024-10-18) / https://www.socialmediatoday.com/news/ig-chief-recommends-posting-carousels-improve-reach/730232/ (2024-10-17)
- 우선순위: 상 — 앱 게시 시 음악 추가. 단, Graph API로 이미지·캐러셀에 음악을 붙이는 파라미터는 확인하지 못함(아래 4-4 참고).

### 2-3. 릴스 vs 캐러셀 성과 (제3자 데이터)
- 내용: Buffer 5,200만+ 게시물 분석에서 인스타 릴스는 캐러셀보다 도달이 36% 높고, 캐러셀은 참여율이 12% 높았다.
- 근거: Buffer 자체 데이터셋(업계 표본, 인과 아님).
- 출처: https://buffer.com/resources/state-of-social-media-engagement-2026/ (2026-03-05)
- 우선순위: 중 — 팔로워 전환은 캐러셀, 신규 도달 실험은 사진 슬라이드쇼형 릴스(또는 음악 캐러셀)로 병행.

### 2-4. 테스트 릴스(Trial Reels): 비팔로워에게 먼저 시험
- 내용: 테스트 릴스는 팔로워에게 보이지 않고 비팔로워에게만 먼저 노출되며, 성과가 좋으면 수동으로 또는 첫 72시간 조회수 기준 자동으로 팔로워에게 공유되도록 설정할 수 있다.
- 근거: Instagram for Creators 공식 발표. 이용 조건(프로페셔널 계정 등)은 원문에서 명확히 추출하지 못함. Graph API 릴스 생성에 `trial_params` 파라미터가 존재함을 API 레퍼런스에서 확인.
- 출처: https://creators.instagram.com/blog/instagram-trial-reels (2024-12-10) / https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media (v26.0 레퍼런스, 2026-09 열람)
- 우선순위: 중 — 사진 몇 장을 이어 붙인 짧은 릴스를 테스트 릴스로 올려 반응 좋은 사진 톤을 찾는 용도.

### 2-5. 비율: 프로필 그리드 3:4, 3:4 업로드 지원
- 내용: 2025년 1월 프로필 그리드 썸네일이 정사각(1:1)에서 세로 3:4로 바뀌었다. 2025년 5월 Mosseri가 "대부분의 폰 카메라 기본값인 3:4 사진을 지원한다"고 밝혔고, 단일·캐러셀 모두 크롭 없이 게시된다. 3:4 = 1080×1440px로 그리드와 정확히 일치.
- 근거: Mosseri 스레드 게시물(1차), 보도.
- 출처: https://www.threads.com/@mosseri/post/DKOIbJkRNIb/ (2025-05 말) / https://petapixel.com/2025/05/29/instagram-finally-adds-support-for-34-aspect-ratio-photos/ (2025-05-29) / 그리드 변경: https://www.kapwing.com/resources/instagrams-new-grid-layout-size-and-dimensions-2025/ (2차, 2025)
- 우선순위: 상 — 앱 게시라면 3:4(1080×1440) 기본.

### 2-6. [주의] Graph API는 3:4를 받지 않는다 — 4:5가 한계
- 내용: Graph API 이미지 사양은 "종횡비 4:5 ~ 1.91:1 범위, JPEG, 최대 8MB, 너비 320~1440, sRGB"다. 3:4(0.75)는 4:5(0.8)보다 세로로 길어 범위 밖이다. API 캐러셀은 최대 10장이며 모든 이미지가 첫 장 비율 기준으로 잘린다(앱은 20장).
- 근거: Meta 개발자 문서(공식).
- 출처: https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media (2026-09 열람) / https://developers.facebook.com/docs/instagram-platform/content-publishing/ (갱신 2026-06-30)
- 우선순위: 상 — API 예약 게시 파이프라인은 4:5(1080×1350)로 내보내고, 캐러셀은 전 장 동일 비율·10장 이하. 그리드에서는 4:5가 3:4 썸네일로 좌우가 약간 잘릴 수 있으니 주요 피사체를 중앙에.

## 3. 해시태그와 검색(SEO)

### 3-1. 해시태그 최대 5개 (2025-12)
- 내용: Instagram은 게시물·릴스 캡션 해시태그를 5개로 제한한다고 밝혔다. 인용: "일반적인 태그 여러 개보다 더 적은(최대 5개) 타깃 해시태그가 성과와 경험을 개선한다." 앞서 1년간 3개 제한 실험도 있었다.
- 근거: Instagram 공지를 인용한 보도(2차 보도).
- 출처: https://www.socialmediatoday.com/news/instagram-implements-new-limits-on-hashtag-use/808309/ (2025-12-18)
- 우선순위: 상.

### 3-2. 해시태그는 도달 레버가 아니라 분류·검색 신호
- 내용: Mosseri는 2024년 2월 해시태그가 도달을 늘리는 데 "효과가 없다"고 했다. Instagram은 캡션·바이오·해시태그의 관련 키워드가 검색 노출에 도움이 된다고 안내하고, Meta 검색 시스템 카드는 해시태그를 검색 결과 유형·예측 대상으로 명시한다. 해시태그 "개수"가 도달을 바꾼다는 1차 근거는 없다.
- 출처: https://www.socialmediatoday.com/news/instagram-implements-new-limits-on-hashtag-use/808309/ (2025-12-18, Mosseri 발언 연표 포함) / https://creators.instagram.com/blog/tips-for-improving-your-reach (2023-05-31) / https://transparency.meta.com/features/explaining-ranking/ig-search/ (갱신 2026-06-23, RecurPost 인용)
- 우선순위: 상 — 태그는 "주제 라벨"로 3~5개. 대형·니치 비율에 대한 1차 권장치는 없음 → 아래 규칙의 비율은 통념(미검증) 기반 운영 가정.

### 3-3. 캡션·바이오·이름 키워드 (인스타 검색 SEO)
- 내용: Instagram은 콘텐츠·캡션·바이오·해시태그에 관련 키워드를 넣어야 검색에서 발견된다고 안내한다. 2025-03-24부터 Graph API 이미지 게시에 `alt_text` 필드가 추가되어 대체 텍스트를 API로 넣을 수 있다.
- 출처: https://creators.instagram.com/blog/tips-for-improving-your-reach (2023-05-31) / https://developers.facebook.com/docs/instagram-platform/content-publishing/ (갱신 2026-06-30)
- 우선순위: 상 — 캡션 첫 문장에 장소·장면 키워드 1~2개(예: "을지로 골목 저녁 필름사진"). alt text가 검색 랭킹에 반영된다는 1차 자료는 없음(통념(미검증)), 접근성 목적으로 작성.

### 3-4. 구글 검색 노출 (2025-07-10~)
- 내용: 2025년 7월 10일부터 18세 이상 공개 프로페셔널 계정의 공개 게시물이 구글 등 검색엔진에 노출될 수 있게 되었고, 설정에서 끌 수 있다.
- 근거: 보도(2차 보도). Instagram 1차 공지 원문은 확인하지 못함.
- 출처: https://ppc.land/instagram-content-becomes-searchable-on-google-starting-july-10/ (2025-07) / https://wersm.com/instagram-content-will-now-be-searchable-on-google/ (2025-07)
- 우선순위: 하 — 캡션 키워드 작성이 인스타 검색과 웹 검색 둘 다에 쓰인다는 정도로만 반영.

## 4. 게시 빈도·시간대·예약 게시

### 4-1. 빈도: 주 3~5회부터 팔로워 증가율이 뚜렷이 오름
- 내용: Buffer의 10만 계정·200만+ 게시물 분석에서 주 3~5회 피드 게시는 주 1~2회 대비 팔로워 증가율을 2배 이상 높였고, 게시물당 도달도 약 12% 높았다(주 10회는 약 24%). 스토리는 제외. Buffer도 "많을수록 무조건 좋다"는 아니라고 단서를 달았다.
- 근거: 제3자 데이터(상관관계).
- 출처: https://www.socialmediatoday.com/news/study-shows-posting-more-instagram-leads-to-more-reach/757633/ (2025-08-13) / https://buffer.com/resources/grow-on-instagram/
- Mosseri의 "주 2회 피드 + 하루 1~2개 스토리" 권장은 여러 2차 글에 인용되나 1차 원문 날짜를 확인하지 못함 → 통념(미검증).
- 우선순위: 상 — 주 3~4회 피드(캐러셀), 품질 유지가 가능한 선에서.

### 4-2. 시간대: 한국 기준
- 내용(국내): Shopify 코리아는 오픈서베이·나스미디어 리포트를 근거로 국내 이용이 출근(07~09시)·점심(11:30~13시)·퇴근 후(19~22시)에 몰리며, 릴스는 19~22시·07:30~09시가 좋다고 정리했다.
- 내용(글로벌, 현지 시간 기준): Buffer 960만 게시물(2024-01~2025-12) 분석에서 수요일이 최고, 금·토가 최저이며, 평일은 대체로 저녁 18~23시가 강하고 목요일만 오전 7~9시가 강했다. 요일별 1순위: 월 19시, 화 19시, 수 12시.
- 근거: 국내는 2차 정리(원 리포트 직접 열람 못 함), 글로벌은 Buffer 자체 데이터.
- 출처: https://www.shopify.com/kr/blog/time-post-instagram (2026-08-20) / https://buffer.com/resources/when-is-the-best-time-to-post-on-instagram/ (2026-09-23 갱신)
- 우선순위: 중 — 초기값으로만 쓰고, 4주 후 인사이트의 팔로워 활동 시간으로 교체. "첫 1시간 반응이 결정적"은 통념(미검증).

### 4-3. Graph API 예약 게시 유의점
- 내용:
  - 24시간 롤링 기준 API 게시 최대 100건(캐러셀 1건으로 계산). 사용량은 `GET /<IG_ID>/content_publishing_limit`로 확인. 문서 일부 섹션에는 아직 50건 표기가 남아 있어 충돌 — 개인 계정 운영에는 무관.
  - 이미지는 JPEG만, 확장 JPEG(MPO·JPS) 불가, 필터·쇼핑 태그 불가. 공개 URL(`image_url`)에서 Meta가 가져가므로 게시 시점에 URL이 살아 있어야 함.
  - 종횡비 4:5~1.91:1, 최대 8MB, sRGB(다른 색공간은 변환됨) → 3:4 불가(2-6).
  - 캐러셀 최대 10장, 첫 장 비율 기준으로 나머지 크롭.
  - `alt_text`(이미지, 2025-03-24~), `collaborators`, 릴스 `trial_params`, `location_id`, `user_tags` 파라미터 존재.
  - API 자체에 "예약 시간" 필드는 없음 — 앱 쪽 스케줄러가 해당 시각에 컨테이너 생성→`media_publish` 호출. 문서는 앱에서도 게시 한도를 자체 관리하라고 권장.
- 근거: Meta 개발자 문서(공식).
- 출처: https://developers.facebook.com/docs/instagram-platform/content-publishing/ (갱신 2026-06-30) / https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media (2026-09 열람)
- 우선순위: 상.

### 4-4. API 게시의 기능 공백
- 내용: API 레퍼런스에서 이미지·캐러셀용 음악 파라미터를 찾지 못했다(`audio_name`은 릴스용). 따라서 "음악 캐러셀 → 릴스 탭 노출"(2-2)은 API 게시로는 재현되지 않을 가능성이 높다.
- 근거: API 레퍼런스 대조(부재 확인은 불완전할 수 있음).
- 출처: https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media
- 우선순위: 중 — 주 1회 정도는 앱에서 음악 캐러셀을 직접 게시하는 혼합 운영 고려.

## 이 계정에 바로 적용할 규칙 10개 (콘텐츠 기획·캡션 에이전트용)

1. **형식 비율**: 주간 피드 게시의 약 70%를 캐러셀(3~7장), 30%를 단일 사진 또는 사진 슬라이드쇼 릴스(7~15초)로 한다. 캐러셀 1·2번 장은 둘 다 단독으로 멈추게 할 만큼 강한 컷으로 둔다(Mosseri "두 번째 장 재노출", 2024-10-17). 비율 수치는 운영 가정이다.
2. **이미지 규격**: Graph API 게시분은 JPEG, sRGB, 1080×1350(4:5), 8MB 이하로 내보낸다. 캐러셀은 전 장 같은 비율, 최대 10장. 3:4(1080×1440)는 앱에서 직접 올릴 때만 쓴다. 주요 피사체는 중앙 80% 안에 둔다(4:5가 3:4 그리드에서 좌우가 잘림).
3. **해시태그**: 게시물당 정확히 3~5개, 캡션 끝에 둔다. 구성은 니치 60%(예: 5개 중 3개, 게시물 수가 적은 구체 태그 — `#을지로골목` `#필름사진일기`), 중형 주제 1개(`#서울산책`), 계정 고유 태그 1개로 한다. 20만 게시물을 넘는 초대형 일반 태그(`#daily` `#감성`)는 쓰지 않는다. 비율은 1차 권장치가 없는 운영 가정이다(5개 상한은 공식, 2025-12).
4. **캡션 첫 줄 키워드**: 첫 문장(약 40자 이내)에 검색될 명사 키워드 2개(장소 + 장면/시간대, 예: "성수동 골목, 비 그친 저녁")를 넣는다. 이어서 2~4줄 짧은 감성 문장, 마지막 줄에 해시태그를 쓴다. 전체 캡션은 300자 이하로 한다.
5. **보내기 유도**: 캡션 마지막 문장은 "이 장면 같이 보고 싶은 사람에게" 같은 공유 동기를 주는 문장이나 질문 1개로 끝낸다. "좋아요 눌러주세요", "팔로우하면 맞팔" 같은 참여 구걸과 품앗이 문구는 금지한다(보내기/도달은 비팔로워 핵심 신호, 2025-01-22).
6. **원본성**: 계정 주인이 직접 찍은 사진만 쓴다. 워터마크·서명·흰 테두리 프레임·다른 앱 로고를 넣지 않는다. 타인 사진 리그램은 30일 기준 게시물의 10% 미만으로 제한하고(원칙은 "대부분 원본", 10%는 안전 마진), 쓸 때는 Collab으로 올린다.
7. **빈도**: 피드는 주 3~4회(캐러셀 중심), 스토리는 게시일마다 1~3개(새 게시물 공유 + B컷 1장)로 한다. 하루 2건 이상 피드 게시는 하지 않는다(품질 유지). API 호출은 하루 5건 이내로 자체 제한한다(공식 한도 100건/24h와 여유를 둠).
8. **게시 시간(KST 초기값)**: 월·화 19:00, 수 12:00, 목 08:00, 일 21:00 중 주 3~4개 슬롯을 쓰고 금·토는 피한다(Buffer 2026-09, Shopify KR 2026-08). 4주 뒤 인사이트의 "팔로워 활동 시간" 상위 2개 슬롯으로 교체한다.
9. **비팔로워 도달 실험**: 격주 1회 사진 4~6장 슬라이드쇼 릴스를 테스트 릴스(72시간 자동 공유 옵션)로 올려 사진 톤·주제를 시험한다. 월 1회는 앱에서 음악을 넣은 캐러셀을 직접 게시해 릴스 탭 노출 자격을 쓴다(API로는 이미지 음악 미지원 추정).
10. **커뮤니티·금지선**: 월 1~2회 비슷한 규모 사진 계정이나 촬영 장소 계정과 Collab(최대 5명 초대)을 하고, 게시 후 24시간 안에 모든 댓글에 답한다. 프로필 이름·바이오에 검색 키워드 2~3개를 넣고, 공개 + 크리에이터 계정을 유지한다. 팔로우·좋아요·남의 게시물 댓글 자동화, 팔로워 구매, 품앗이, 비공식 API는 전면 금지한다(자동화 범위 = Graph API 공식 게시 + 내 게시물 댓글 답글).

## 확인하지 못한 부분
- Meta 시스템 카드(Feed·Explore·Search·Reels Chaining)와 Instagram 도움말(추천 가이드라인·이용약관)은 JS 렌더링이라 본문을 직접 파싱하지 못했다. 해당 내용은 RecurPost의 인용(열람일 2026-08-24)과 검색 요약으로 확인했다.
- "보내기가 최중요 신호"라는 2025~2026 Mosseri 발언의 텍스트 원문, "2026년 신규 랭킹 신호 2개" 주장은 1차 출처로 확인하지 못했다.
- 저장(save)의 상대 가중치, 해시태그 대형/니치 최적 비율, 게시 후 캡션 수정 영향은 1차 자료가 없다.
- Mosseri의 "주 2회 피드 + 하루 1~2 스토리" 권장의 원문 날짜와 테스트 릴스 이용 자격 조건을 확인하지 못했다.
- 한국 게시 시간의 원 데이터(오픈서베이·나스미디어 리포트)는 직접 열람하지 못했고 Shopify KR 요약에 의존했다.
- Graph API의 이미지·캐러셀 음악 첨부 지원 여부는 "레퍼런스에서 찾지 못함" 수준이다.
